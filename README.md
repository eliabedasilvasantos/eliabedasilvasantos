## About

I'm part of the **Fovea AI** project at **Volarin Technologies**, contributing to geospatial intelligence for maritime operations.

My current work involves Python, PostgreSQL and PostGIS: processing vessel positions, testing spatial queries and working with simulated operational data. My learning and development interests also include **machine learning, AI model training and geospatial data engineering**.

<br>

## Fovea AI

**Maritime geospatial intelligence · Early development**

The project starts with vessel monitoring and port-area analysis. Its technical direction includes bringing spatial data processing and machine learning into operational workflows.

| Area | Work and direction |
| :--- | :--- |
| **Vessel monitoring** | Position data, trajectory analysis and gaps in simulated tracking data |
| **Geospatial analysis** | Port areas, spatial relationships and geographic event detection |
| **Data engineering** | Exploring ingestion, validation and preparation of maritime datasets |
| **Machine learning** | Planned experiments in anomaly detection, movement patterns and prediction |
| **AI model training** | Planned work on feature engineering, training pipelines and model evaluation |
